# Отчёт по работе «Обработка списка студентов»

## 1. Реализованные функции

- `Temeshova_format_students(students)` с помощью `map` преобразует список
  студентов в список строк вида `Имя: {name}, Оценка: {grade}`;
- `Temeshova_filter_high_grade(students)` с помощью `filter` оставляет студентов
  с оценкой строго выше `4.0`;
- `Temeshova_average_age(students)` с помощью `reduce` суммирует возраст
  переданных студентов и вычисляет их средний возраст.

## 2. Среда выполнения

Решение разработано для Python 3.9.6. Используется только требуемая в задании
функция `reduce` из стандартного модуля `functools`. `map`, `filter`, `list` и
`len` являются встроенными функциями Python и не требуют импортов.

В программе отсутствуют пользовательский ввод, циклы и промежуточные переменные
с данными. Все три функции записаны с помощью `lambda` и имеют префикс
`Temeshova_`, как в предыдущих работах. Демонстрационные вызовы используют
только значения, непосредственно записанные в коде.

## 3. Преобразование с помощью map

`Temeshova_format_students` передаёт каждый словарь студента лямбда-функции,
которая формирует строку из значений `name` и `grade`. Функция `map` возвращает
итератор, а `list` преобразует его в новый список строк.

Для заданных данных результат имеет вид:

```python
[
    "Имя: Анна, Оценка: 4.5",
    "Имя: Борис, Оценка: 3.8",
    "Имя: Виктор, Оценка: 4.2",
    "Имя: Галина, Оценка: 4.9",
    "Имя: Дмитрий, Оценка: 3.5",
]
```

## 4. Отбор с помощью filter

`Temeshova_filter_high_grade` проверяет условие
`student["grade"] > 4.0` для каждого словаря. Студент с оценкой ровно `4.0` не
попадёт в результат, поскольку сравнение строгое.

Из заданного списка проходят отбор:

- Анна с оценкой `4.5`;
- Виктор с оценкой `4.2`;
- Галина с оценкой `4.9`.

Исходный список и словари не изменяются. `filter` создаёт итератор подходящих
элементов, а `list` преобразует его в новый список.

## 5. Средний возраст с помощью reduce

`Temeshova_average_age` принимает уже отобранный список студентов. Начальное
значение аккумулятора равно нулю. На каждом шаге `reduce` прибавляет к общей
сумме возраст очередного студента:

```text
0 + 20 + 19 + 21 = 60
```

Полученная сумма делится на количество отобранных студентов:

```text
60 / 3 = 20.0
```

Для пустого списка функция возвращает `0.0`, поэтому деления на ноль не
возникает.

## 6. Сравнение с императивным подходом

В функциональном решении `map`, `filter` и `reduce` явно разделяют три операции:
преобразование, отбор и свёртку. Код хорошо читается, когда каждая операция
короткая и выражает одно действие. Не требуется вручную создавать результирующие
списки, изменять их через `append` или обновлять переменную суммы.

Императивный вариант с обычным циклом может читаться проще, если все действия
нужно выполнить за один проход или если внутри много условий. Он также позволяет
легко поставить отладочный вывод на каждом шаге.

В императивном коде выше риск забыть добавить элемент в список, неправильно
обновить сумму или счётчик и получить ошибку при вычислении среднего значения.
В функциональном коде меньше изменяемого состояния, но слишком длинные цепочки
вложенных вызовов могут ухудшить читаемость. В этой работе операции оставлены
отдельными функциями, поэтому их назначение видно по именам.

## 7. Чистота функций и демонстрация

Все три функции детерминированы, не выполняют ввод-вывод, не изменяют исходные
списки и словари и не используют внешнее состояние. Вызовы `print` расположены
отдельно от функций и нужны только для демонстрации результатов всех трёх
уровней.

# Отчёт по работе «Анализ продаж»

## 1. Цель работы

Цель работы — разработка чистых функций для обработки таблицы продаж.

Мной реализованы следующие функции:

1. `Temeshova_parse_csv` — разбор строки CSV;
2. `Temeshova_compute_revenue` — расчёт общей выручки;
3. `Temeshova_top_item` — поиск строки с максимальной выручкой.

## 2. Среда выполнения

Программа разработана и проверена в Python 3.9.6. Операторы `import` и внешние
библиотеки не используются. Решение основано на лямбда-функциях и встроенных
операциях Python.

## 3. Формат входных данных

Функция `Temeshova_parse_csv` принимает данные в виде строки. Первая строка
содержит заголовок:

`date,item,quantity,price`

Каждая следующая строка содержит одну продажу. Значения разделяются запятыми.
Дата записывается в формате `ГГГГ-ММ-ДД`. Название товара записывается текстом
без запятой. Количество и цена записываются числами, например `2` и `500`, а не
словами `два` и `пятьсот`.

Пустая строка также является допустимым входным значением. Для неё функция
возвращает пустой список.

Таким образом, область допустимых данных задаётся положительным описанием
формата, а не перечислением всех возможных ошибочных вариантов.

## 4. Разбор CSV

Лямбда-функция `Temeshova_parse_csv` разделяет исходный текст на строки с
помощью `splitlines()`. Заголовок и строки продаж разделяются на значения с
помощью `split(",")`. Функция `filter` исключает пустые строки, а функция `map`
преобразует каждую оставшуюся строку в словарь. Переменная цикла `for` не
используется.

Функции `zip` и `dict` объединяют названия столбцов со значениями. Результатом
является новый список словарей. Все ключи и значения после разбора имеют тип
`str`.

## 5. Расчёт общей выручки

Лямбда-функция `Temeshova_compute_revenue` принимает список словарей. Для
каждой строки значения `quantity` и `price` преобразуются в тип `float` и
перемножаются. Функция `map` применяет расчёт ко всем строкам, а `sum` вычисляет
общую сумму.

Для пустого списка результат равен `0.0`.

## 6. Поиск максимальной выручки

Лямбда-функция `Temeshova_top_item` использует встроенную функцию `max`.
Параметр `key` содержит лямбда-функцию, которая рассчитывает выручку отдельной
строки.

Для непустого списка возвращается весь словарь строки с максимальной выручкой.
Для пустого списка возвращается `None`. При равной выручке возвращается первая
подходящая строка.

## 7. Использование лямбда-функций

В программе отсутствуют промежуточные присваивания и изменяемые глобальные
переменные. В глобальной области находятся только три уникальных имени,
связанных с лямбда-функциями.

Промежуточные переменные отсутствуют. Параметры лямбда-функций имеют уникальные
имена `temeshova_data`, `temeshova_rows`, `temeshova_line` и `temeshova_row`.
Эти параметры являются локальными: они существуют только во время конкретного
вызова и не изменяют общую область программы.

Функции `map`, `filter` и `max` являются функциями высшего порядка, поскольку
принимают другие функции в качестве аргументов.

## 8. Проверка чистоты

### Детерминированность

Результат каждой функции зависит только от переданных аргументов. При одинаковых
входных данных возвращается одинаковый результат.

### Тотальность

Функции определены для всех значений из заявленных областей определения:

- `Temeshova_parse_csv` принимает пустую строку или строку установленного
  формата CSV;
- `Temeshova_compute_revenue` принимает список словарей с числовыми значениями
  `quantity` и `price`;
- `Temeshova_top_item` принимает список словарей того же вида, включая пустой
  список.

Текстовые записи чисел не относятся к установленной области определения.
Например, значением количества является `2`, но не `два`.

### Отсутствие побочных эффектов

Реализованные функции:

- не выполняют импортов;
- не осуществляют ввод и вывод;
- не читают и не записывают файлы;
- не используют сеть, время и случайные значения;
- не изменяют переданные списки и словари;
- не изменяют глобальное состояние.

`Temeshova_parse_csv` создаёт новый список и новые словари, а
`Temeshova_compute_revenue` возвращает новое числовое значение.
`Temeshova_top_item` возвращает один из исходных словарей, но не изменяет его.
Все переданные аргументы используются только для чтения.

## 9. Типы принимаемых и возвращаемых значений

- `Temeshova_parse_csv` принимает `str` и возвращает `list[dict]`;
- `Temeshova_compute_revenue` принимает `list[dict]` и возвращает `float`;
- `Temeshova_top_item` принимает `list[dict]` и возвращает `dict` или `None`.

## 10. Результаты проверки

Проверка выполнена на таблице из трёх строк:

- 2 единицы товара «Книга» по цене 500;
- 10 единиц товара «Тетрадь» по цене 40;
- 3 единицы товара «Ручка» по цене 100.

Получены значения выручки 1000, 400 и 300 соответственно. Общая выручка
составила `1700.0`. Функция `Temeshova_top_item` вернула словарь товара «Книга»
с датой `2026-09-01`.

Дополнительно проверены пустая строка CSV, пустой список продаж, повторный вызов
с одинаковыми аргументами и отсутствие изменения исходных данных.

## 11. Уникальность имён

Для имён функций используется префикс `Temeshova_`. Он исключает совпадение с
обычными именами `parse_csv`, `compute_revenue` и `top_item` при объединении
исходного кода.

## 12. Заключение

В ходе работы реализованы три чистые лямбда-функции без импортов, промежуточных
присваиваний и изменяемых глобальных данных. Функции выполняют разбор строки
CSV, расчёт общей выручки и поиск строки с максимальной выручкой.

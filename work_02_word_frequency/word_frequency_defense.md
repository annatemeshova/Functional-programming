# Отчёт по работе «Частота слов»

## 1. Реализованные функции

- `Temeshova_split_words(text)` приводит текст к нижнему регистру и выделяет слова,
  считая знаки препинания разделителями;
- `Temeshova_count_word_frequencies(words)` создаёт новый словарь частот и не изменяет
  исходный список;
- `Temeshova_top_word(freq)` возвращает слово с наибольшей частотой, а для пустого
  словаря — `None`.

При одинаковой максимальной частоте `Temeshova_top_word` возвращает первое слово в
порядке словаря. Словари Python 3.7+ сохраняют порядок добавления ключей.

## 2. Среда выполнения

Решение разработано и проверено в Python 3.9.6. Импорты, сторонние и
стандартные библиотеки не используются.

## 3. Проверка чистоты

Все три функции являются детерминированными: одинаковые аргументы дают
одинаковые результаты. Функции не выполняют ввод-вывод, не работают с файлами,
сетью, временем или случайными числами и не изменяют глобальное состояние.

Исходные строка, список и словарь используются только для чтения. Каждая
функция возвращает новое значение либо ссылку на уже существующий неизменяемый
ключ словаря. Следовательно, наблюдаемых побочных эффектов нет. В теле функций
нет промежуточных присваиваний.

## 4. Пустой ввод

Для пустой строки получается следующая цепочка результатов:

```python
Temeshova_split_words("")                         # []
Temeshova_count_word_frequencies([])              # {}
Temeshova_top_word({})                            # None
```

Строка, состоящая только из знаков препинания, также преобразуется в пустой
список слов.

## 5. Пример

```python
Temeshova_top_word(Temeshova_count_word_frequencies(Temeshova_split_words("Кот, пёс и КОТ!")))
# Результат: "кот"
```

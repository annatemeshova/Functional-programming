# Отчёт по работе «Состояние загрузки данных»

## 1. Среда выполнения

Решение разработано для Python 3.9.6. Используются только обязательные модули
стандартной библиотеки: `enum`, `dataclasses` и `typing`. В программе нет ввода,
циклов и промежуточных переменных с данными. В конце файла добавлен вывод для
демонстрации работы реализованных типов и функций.

## 2. Тип-сумма состояния загрузки

`TemeshovaLoadState` создан с помощью `Enum` и содержит три взаимоисключающих
варианта: `LOADING`, `SUCCESS` и `ERROR`. В каждый момент значение этого типа
может находиться только в одном из трёх состояний.

## 3. Тип-произведение пользователя

`TemeshovaUser` объединяет три поля: имя, возраст и адрес электронной почты.
Декоратор `@dataclass(frozen=True)` запрещает изменять поля созданного объекта.
Тип является произведением, поскольку одно значение пользователя содержит
одновременно значение каждого из трёх полей.

## 4. Тип результата

`TemeshovaResult[T, E]` является объединением двух вариантов:

- `TemeshovaSuccess[T]` хранит успешное значение типа `T`;
- `TemeshovaFailure[E]` хранит ошибку типа `E`.

Функция `Temeshova_users_result` возвращает `TemeshovaFailure` с сообщением
`Список пользователей пуст`, если получает пустой список. Для непустого списка
она возвращает `TemeshovaSuccess`. Функция `Temeshova_load_users` передаёт ей
демонстрационный список неизменяемых пользователей.

## 5. Мощность типов

У `TemeshovaLoadState` ровно **3 значения**.

Для типа результата действует формула мощности суммы:

```text
|Result[list[User], str]| = |list[User]| + |str|
```

Множества строк, целых чисел, пользователей и конечных списков пользователей
счётно бесконечны. Сумма двух счётно бесконечных множеств также счётно
бесконечна. Следовательно, `Result[list[User], str]` имеет счётно бесконечное
число возможных значений. Если не предполагать неограниченные типы Python,
точное конечное число без ограничения длины строк, списка и диапазона возраста
определить нельзя.

## 6. Демонстрационный вывод

При запуске файла выводятся результаты проверки заполненного и пустого списков,
значения трёх состояний загрузки и ответы уровня 4: количество значений
`LoadState` равно трём, а множество значений `Result[list[User], str]` счётно
бесконечно. Вывод расположен вне функций и нужен только для демонстрации.

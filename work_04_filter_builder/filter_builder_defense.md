# Отчёт по работе «Построитель фильтров»

## 1. Реализованные функции

- `Temeshova_filter_by(key)(value)(items)` возвращает новый список словарей,
  у которых значение по ключу `key` равно `value`;
- `Temeshova_filter_by_category(value)(items)` фильтрует словари по ключу
  `category`. Ключ заранее зафиксирован с помощью `functools.partial`;
- `Temeshova_greater_than(threshold)(x)` возвращает `True`, если `x` строго
  больше `threshold`;
- `Temeshova_filter_greater_than(threshold)(items)` применяет предикат
  `Temeshova_greater_than` вместе со встроенной функцией `filter` и возвращает
  список подходящих чисел.

## 2. Среда выполнения

Решение разработано для Python 3.9.6. Используется только указанный в задании
объект `partial` из модуля `functools`. В программе отсутствуют ввод, циклы и
промежуточные переменные с данными. Все функции записаны с помощью `lambda` и
имеют префикс `Temeshova_`, как в предыдущих работах. В конце файла расположен
демонстрационный вывод: функции вызываются непосредственно с константами.

## 3. Ручное каррирование

Функция `Temeshova_filter_by` получает аргументы по одному. Сначала передаётся
ключ, затем искомое значение, после чего список словарей. Каждый вызов возвращает
следующую функцию до тех пор, пока не будут переданы все данные.

Например, вызов

```python
Temeshova_filter_by("category")("fruit")(
    [
        {"name": "apple", "category": "fruit"},
        {"name": "carrot", "category": "vegetable"},
        {"name": "banana", "category": "fruit"},
    ]
)
```

возвращает словари с товарами `apple` и `banana`. Функция использует обращение
`item[key]`, поэтому её область допустимых входных данных — словари, содержащие
переданный ключ.

## 4. Частичное применение

`Temeshova_filter_by_category` создана на основе `Temeshova_filter_by` с помощью
`partial`. Частичное применение заранее передаёт исходную функцию обёртке, а
обёртка фиксирует ключ `category`. Пользователю остаётся указать только категорию
и список:

```python
Temeshova_filter_by_category("fruit")(
    [
        {"name": "apple", "category": "fruit"},
        {"name": "carrot", "category": "vegetable"},
    ]
)
```

## 5. Предикат сравнения

`Temeshova_greater_than` также каррирована. После передачи границы возвращается
предикат для одного числа. Функция `Temeshova_filter_greater_than` передаёт этот
предикат встроенной функции `filter`:

```python
Temeshova_filter_greater_than(5)([1, 6, 8, 2, 9])
# Результат: [6, 8, 9]
```

## 6. Преимущества каррирования

Каррирование позволило поэтапно настраивать универсальные функции. Из общего
фильтра получен фильтр по категории, а из общего сравнения — предикат с уже
заданной границей. Такие подготовленные функции удобно передавать функциям
высшего порядка, в частности `filter`, и повторно применять к разным спискам.

Без каррирования обойтись можно: ключ, значение и список можно передавать одной
обычной функции одновременно, а для `filter` использовать отдельную
лямбда-функцию. Однако тогда настройку фильтра пришлось бы повторять в каждом
месте вызова. В этой работе каррирование уменьшает повторение и наглядно
разделяет настройку фильтра и его применение.

## 7. Чистота функций

Реализованные функции детерминированы, сами не выполняют ввод-вывод, не изменяют
переданные списки и словари и не используют внешнее состояние. `filter` создаёт
итератор подходящих элементов, а `list` преобразует его в новый список.
Локальные параметры лямбда-функций существуют только во время вызова и не
являются промежуточными глобальными переменными. Вызовы `print` находятся
отдельно от функций и нужны только для демонстрации.

## 8. Демонстрационный вывод

При запуске файла показываются:

- фильтрация словарей по ключу `category` и значению `fruit`;
- фильтрация по категории `vegetable` через функцию, созданную с `partial`;
- результаты `True`, `False` и граничная ситуация, когда число равно границе;
- список чисел, строго превышающих пять.

Для демонстрации используются только константы. Дополнительные переменные с
исходными данными или результатами не создаются.
